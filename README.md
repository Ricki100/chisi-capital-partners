# Chisi Capital Partners website

Static website for Chisi Capital Partners, with a page for its sister organisation, the Centre for Impactful Entrepreneurs (CIE).

## Deploy
Deploy the contents of `dist/` to any static host. No server-side code is required.
Preview locally: `python -m http.server 4173 --directory dist`

## Stack
- Tailwind CSS 3.4 (compiled) + custom CSS (`dist/assets/style.css`)
- GSAP 3.13 with ScrollTrigger and SplitText, Lenis smooth scrolling
- CSS View Transitions for page-to-page navigation
- Full-viewport photographic hero on every page
- Reduced-motion users get a static, fully readable site

## Imagery
Photographs in `dist/assets/img/` are illustrative images created with Magnific AI and stored as WebP. The people shown are not Chisi staff, clients or partners (see `photo-credits.html`).

## Editing
Pages are generated by `build.py` from the client's copy document (`.docx`, kept outside the repo in the parent folder): `python build.py`.

## Enquiries
The contact form prepares a local text brief for download; it does not send or store data. Connect an approved form endpoint and update the privacy notice before enabling online submission.
