# Chisi Capital Partners website

Deploy the contents of `dist/` to any static web host. No server-side code is required. Open `dist/index.html` directly or run `python -m http.server 4173 --directory dist` from this directory.

The ten HTML pages use locally compiled Tailwind CSS 3.4.17, custom CSS, and locally bundled GSAP 3.13.0 (ScrollTrigger + SplitText) with Lenis 1.3.4 smooth scrolling. Every page opens with a full-viewport (100vh) photographic hero. Photography lives in `dist/assets/img/` as WebP; the images are illustrative and were created with Magnific AI (see `photo-credits.html`). Cross-page transitions use the CSS View Transitions API where supported. Reduced-motion preferences disable animation and smooth scrolling; if scripts fail, content is revealed after 3.5 seconds. Manrope loads through a Google Fonts stylesheet URL. No analytics or tracking scripts are installed.

The Pexels photos in `dist/assets/photos/` and the original `dist/assets/logo.png` are no longer referenced and can be deleted.

## Editing

Page content is generated by `build.py` from the supplied DOCX and curated homepage content. Run `python build.py` while the source document remains in the parent folder. For deployment-only changes, edit the HTML in `dist/` directly.

Rebuild Tailwind after changing utility classes:

```
npm ci
npx tailwindcss -i input.css -o dist/assets/tailwind.css --minify
```

## Enquiries

The contact form validates input and downloads a local text brief. It does not send messages or save data. The real telephone and office address are displayed. Connect an approved form endpoint and update the privacy notice before enabling online submission. Current website notices describe the static implementation; the supplied business blueprint calls for legal review before public launch.
